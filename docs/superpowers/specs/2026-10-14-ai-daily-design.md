# AI 新鲜事日报 —— 设计说明

日期：2026-10-14

## 目标

一个本地静态网站，每天看一份中文 AI 新闻日报。内容由用户手动触发 Claude 生成，不依赖任何定时任务或在线服务。

## 触发方式

- 项目级技能：`.claude/skills/ai日报/SKILL.md`，用户输入 `/ai日报` 或说“更新今天的 AI 新鲜事”时调用。
- 一次运行的步骤：
  1. 读取 `data/manifest.js` 和最近 3 期数据，记下已报道过的事件，避免重复。
  2. 联网搜索过去 24–48 小时的 AI 新闻，国内、国外来源都要搜。
  3. 挑出 12–16 条，写出摘要，生成当天的数据文件。
  4. 更新 `data/manifest.js`。同一天再次运行时覆盖当天的数据文件，manifest 中不重复添加日期。
- 联网失败或搜到的可靠新闻不到 8 条时：不写文件，告诉用户原因，已有内容保持不变。

## 内容规则

- 分类（四类都要覆盖）：`model`（模型与产品发布）、`industry`（行业动态：融资、收购、人事、政策）、`research`（研究前沿）、`tools`（实用工具、开源项目、玩法）。
- 地区：`cn`（国内）、`intl`（国外），两者大约各占一半（差距不超过 2 条）。
- 每条都要有可访问的原文链接。没有可靠来源、或超出 48 小时的消息不收录。
- 全部用简体中文。标题不超过 30 字，摘要 2–3 句。

## 文件结构

```
ai新鲜事/
├─ index.html              页面模板（固定不变，内含样式和脚本）
├─ data/
│  ├─ manifest.js          window.AI_DAILY_MANIFEST = ["2026-10-14", ...]（新日期排在前面）
│  └─ YYYY-MM-DD.js        每天一个数据文件
└─ .claude/skills/ai日报/SKILL.md
```

用 `.js` 而不用 `.json`，是为了让双击打开（file:// 协议）时页面也能加载数据：页面通过动态插入 `<script>` 标签来读取。

## 数据格式

```js
window.AI_DAILY = window.AI_DAILY || {};
window.AI_DAILY["2026-10-14"] = {
  date: "2026-10-14",
  highlights: ["一句话看点1", "一句话看点2", "一句话看点3"],
  items: [
    {
      title: "标题",
      summary: "2–3 句中文摘要。",
      category: "model",       // model | industry | research | tools
      region: "intl",          // cn | intl
      source: "来源名称",
      url: "https://..."
    }
  ]
};
```

## 页面

- 加载 manifest，默认显示最新一期。URL 带 hash（如 `#2026-10-14`）时显示对应那一期，方便收藏和后退。
- 日期列表：宽屏时在左侧栏，手机上是顶部可横向滚动的一行。
- 顶部是“今日看点”（3 条），下面是新闻卡片：标题（链接到原文，新标签页打开）、摘要、分类标签、地区标签、来源名称。
- 筛选：分类（全部 / 四类）和地区（全部 / 国内 / 国外），两组可以组合使用，前端实时过滤。
- 跟随系统的深色/浅色模式，手机宽度下没有横向滚动。
- 不引用任何外部 CDN 或字体，断网也能完整显示。
- 动效参照 React Bits 用原生 CSS/JS 手写，不引入框架，也不需要打包：标题逐字模糊浮现、“今日看点”流光文字、卡片依次浮入、卡片跟随鼠标的光斑。系统开启“减少动态效果”时全部关闭。（讨论过 React/Vue/Preact + React Bits，因为每天的生成只写数据文件，框架没有带来好处，反而多了打包和依赖。）
- 异常情况：manifest 为空时显示“还没有日报，在 Claude Code 里运行 /ai日报 生成第一期”；某一期的数据文件加载失败时显示错误提示，其他日期仍可切换。

## 验证

- 用一份示例数据，在浏览器里以 file:// 打开检查：切换日期、组合筛选、深色模式、手机宽度。
- 第一次真实运行技能后，检查生成的数据格式正确、链接有效、分类和地区比例符合规则。

## 新增板块（2026-10-14 补充）

每期在 AI 新闻之后依次是三个板块，字段和规则以 `.claude/skills/ai日报/SKILL.md` 和 `scripts/validate.mjs` 为准：

- **国内企业动态** `corp`（5–8 条）：国内大企业的裁员、质量召回、监管处罚、组织人事、经营、争议，不限于 AI；涉及纠纷的必须写上回应。
- **工具推荐** `apps`（12–16 个）：免费、好用的 Windows 软件，优先选 GitHub 开源项目，办公、编程、系统、娱乐四类每期都要有，不和往期重复；Star 数和安装包大小用 GitHub API 查实。
- **AI 落地观察** `insights`（2–3 条）：行业应用、使用方式、新职业，注明数据时间 `asOf`。

页面顶部的“日报 / 工具库”可以切换视图。工具库（`#tools`）汇总所有往期推荐过的工具，可以按分类筛选，也可以按名称或用途搜索。

## 实时热点与自动发布（2026-10-14 补充）

结合了 TrendRadar（国内热榜、关注词分组）和 AI-Search（AI 资讯源、GitHub Actions + Pages）的优点，代码是自己写的：

- `scripts/crawl.mjs`：用 Node 22 写，不装任何依赖。它从三类来源抓取：经 newsnow 接口抓取的 13 个国内热榜、`config/sources.json` 里的 RSS 源，以及 GitHub 最近 7 天新建、Star 最多的仓库。结果写入 `data/hot.js`（`window.AI_HOT`）。
- 关注词分组在 `config/topics.json`。英文关键词按整词匹配。`exclude` 里的词会先从标题里去掉再匹配。`standalone: false` 的分组（“出事了”）单独命中不收录，必须同时命中其他分组，避免社会新闻刷屏。
- 热榜条目只收录命中关注词的；RSS 条目只收录 48 小时内的，标了 `aiOnly` 的源还必须命中 AI 分组。链接只放行 https；热榜链接还必须属于对应平台的域名。
- 部分源失败不影响整体结果；全部失败时不覆盖旧文件。
- `.github/workflows/update.yml` 每 3 小时运行一次：测试 → 校验日报 → 抓取 → 提交 `data/hot.js` → 发布到 GitHub Pages。推送新日报时也会触发。
- 页面新增“实时热点”标签（`#hot`），分国内热榜、AI 资讯、GitHub 本周新项目三块，可以按分组筛选和搜索，底部显示每个数据源的状态。
- `/ai日报` 会把 `data/hot.js` 当作候选线索，但每条都必须核实原文；生成后自动提交并推送。

## 不做的事

- 不做定时自动更新、在线发布、搜索、收藏、评论。
